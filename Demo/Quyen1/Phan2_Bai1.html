Vị trí xuất hiện đầu tiên của N trong dãy 123456789101112…

Kỹ thuật cốt lõi: nối các số 1, 2, 3, … thành một xâu dài rồi dùng phép tìm xâu con. Điểm mấu chốt: N có thể "vắt ngang" ranh giới giữa hai số liên tiếp.

Đề bài

Ghép liên tiếp các số thập phân 1, 2, 3, … ta được dãy 12345678910111213… Tìm vị trí xuất hiện đầu tiên của số N trong dãy này (đánh số vị trí từ 1). Với 1 ≤ N ≤ 100000.

Ví dụ: N = 15 → 20; N = 34 → 3; N = 142 → 73.

Minh họa từng bước

Chọn ví dụ: hoặc tự nhập (1–300):
Bước 0 / 0
Cần tìm N = 15
Dãy đang được nối (mỗi khung = một số vừa nối; số nhỏ bên dưới mỗi chữ số = vị trí của nó trong dãy)
Nhấn "Tiến" để bắt đầu nối số 1.
Sẵn sàng.

Code tham khảo

C++
Python
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int n;
    cin >> n;

    // Bước 1: nối các số 1, 2, ..., n thành một xâu dài
    string day = "";
    for (int k = 1; k <= n; k++)
    {
        day += to_string(k);   // dùng += (KHÔNG viết day = day + ...) để không bị chậm
    }

    // Bước 2: tìm xâu con n trong xâu day
    string can_tim = to_string(n);
    int vi_tri = day.find(can_tim);   // find trả về chỉ số tính từ 0

    // Bước 3: đề đánh số từ 1 nên cộng thêm 1
    cout << vi_tri + 1;
    return 0;
}
def giai(n):
    # Bước 1: nối các số 1, 2, ..., n thành một xâu dài
    cac_so = []
    for k in range(1, n + 1):
        cac_so.append(str(k))
    day = "".join(cac_so)

    # Bước 2: tìm xâu con n trong xâu day
    can_tim = str(n)
    vi_tri = day.find(can_tim)   # find trả về chỉ số tính từ 0

    # Bước 3: đề đánh số từ 1 nên cộng thêm 1
    return vi_tri + 1


if __name__ == "__main__":
    n = int(input())
    print(giai(n))
Vì sao chỉ cần nối đến N là đủ? Chính số N luôn xuất hiện nguyên vẹn khi ta nối tới số N, nên vị trí đầu tiên chắc chắn nằm trong xâu 1…N (có thể sớm hơn, như N = 142 xuất hiện ở "41|42").

Độ dài xâu tối đa: 9 + 90×2 + 900×3 + 9000×4 + 90000×5 + 6 (số 100000) ≈ 488 895 ký tự — rất nhỏ, tìm xâu con chạy tức thì.

Lỗi dễ mắc (Python/C++): viết day = day + to_string(k) sẽ sao chép cả xâu mỗi lần lặp → hàng chục tỷ thao tác với N = 100000 → TLE. Dùng += (C++) hoặc "".join(list) (Python).
