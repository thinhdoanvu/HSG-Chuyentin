Đếm ký tự

Kỹ thuật cốt lõi: mảng đếm tần suất — mỗi ký tự có một "ô" riêng để đếm số lần xuất hiện, phân biệt chữ hoa/thường.

Đề bài

Nhập từ bàn phím một xâu ký tự s. Hãy đếm và in ra số lượng ký tự xuất hiện ít nhất 2 lần trong xâu s (có phân biệt chữ hoa và chữ thường). Xâu S có không quá 255 ký tự.

Cách làm: d[c] = số lần ký tự c xuất hiện trong s, sau đó đếm số ký tự c có d[c] > 1.

Minh họa từng bước

Bước 0 / 0
Xâu s (đang duyệt từng ký tự)
Mảng đếm d[c] (chỉ tạo ô khi gặp ký tự lần đầu)
Nhấn "Tiến" để bắt đầu duyệt xâu.
Sẵn sàng. Ví dụ minh họa: s = "abcbMbdmccccd".

Code tham khảo

C++
Python
#include <bits/stdc++.h>
using namespace std;
#define ll long long

ll d[1000], res;
string s;

int main()
{
    getline(cin, s);
    for (int i = 0; i < s.size(); i++)
    {
        d[s[i]]++;
    }
    for (int i = 0; i <= 500; i++)
    {
        if (d[i] > 1)
        {
            res++;
        }
    }
    cout << res;
}
def giai(s):
    d = {}
    for ch in s:
        d[ch] = d.get(ch, 0) + 1
    res = 0
    for ch in d:
        if d[ch] > 1:
            res += 1
    return res

if __name__ == "__main__":
    s = input()
    print(giai(s))
